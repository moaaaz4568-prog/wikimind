# قائمة تحقق جودة الماستر — مبنية على أخطاء الدراسة

> طبّقها كاملة على كل ماستر جديد قبل التسليم. كل بند يجب أن يكون ✓ أو مسجَّلاً
> كاستثناء موثق (ما الاستثناء ولماذا). لا تعلن نجاحاً قبل التحقق من ملف الإخراج
> على القرص بنفسك [REPORTED — قاعدة «الدليل قبل الإعلان» من سجل أخطاء argon].
> الأرقام المرجعية من `references/structure-spec.md` و`references/study.md`
> (كلها OBSERVED ما لم يُذكر خلافه).

## أ) الهيكل (قبل قراءة المحتوى)

- [ ] الماستر = ترويسة `## Master_<Name>` + سطر مسار `` `NN_topic/Master_Name.md` `` + 3 أسطر محتوى فقط.
- [ ] الترتيب §1 ثم §4 ثم §16، بلا قسم إضافي أو ناقص أو بترتيب مختلف.
- [ ] كل قسم = سطر واحد فعلاً (لا أسطر حقيقية داخل القسم).
- [ ] صيغة عناوين الأقسام واحدة ثابتة في الأقسام الثلاثة (المقترحة: الصيغة A `## §N — <عنوان>`).
- [ ] لا عنوان قسم مفقود (نقطة فقط `.`) — العيب الموثق في Lead_Qualification وVSL_System.
- [ ] لا frontmatter في الماستر (القالب القديم له frontmatter؛ الماسترز الحقيقية بلا أي frontmatter).
- [ ] سطر فاصل `---` بعد الماستر، وسطر فارغ قبله وبعده.
- [ ] اسم الماستر `Master_<Pascal_Case>` بلا مسافات، ومسار المصدر يطابق الاسم حرفياً.

## ب) الأطوال والسقف (قِسها بأمر، لا بالتقدير)

- [ ] §1 بين 76 و371 كلمة (الوسيط 168) — خارج النطاق يستدعي مراجعة النطاق، لا حذفاً أعمى.
- [ ] §4 بين 294 و916 كلمة (الوسيط 853) وحصته 43–80% من حروف الماستر.
- [ ] §16 بين 61 و875 كلمة (الوسيط 217).

- [ ] **لا قطع منتصف الكلمة**: كل قسم ينتهي بجملة مكتملة، لا بكلمة مبتورة ولا رقم معلّق.
- [ ] كل قسم مختوم بـ ` --- ` داخل السطر — غياب الخاتم علامة قطع محتملة لا معادَلة (4 أقسام غير مقطوعة بلا خاتم).

- [ ] لا كتلة كود ولا خلية جدول مقطوعة في المنتصف.

## ج) الروابط والإحالات

- [ ] **رابط موجود فعلاً كملف؟** كل رابط `[[Concept_...]]` تحققت من وجود ملفه بالاسم الدقيق (وحساس لحالة الأحرف) قبل الكتابة وبعدها. رابط بلا ملف = فشل هذا البند.
- [ ] لا روابط `[[Concept_...]]` لمفاهيم غير موجودة — اذكر المفهوم كنص حر بلا [[ ]] إن لم يوجد ملفه.
- [ ] لا روابط `[[Master_...]]` إطلاقاً (صفر في الـ 39).
- [ ] لا روابط Markdown `[…](…)` ولا روابط خارجية (http/https) — صفر في الـ 39.
- [ ] **لا إحالات لأقسام ميتة**: لا ذكر لـ §2/§3/§5–§15 داخل النص إطلاقاً (الإحالات المعلّقة موثقة في 4 ماسترز: §3.1، §9، §11، §15.3، §15.8، §15.11).
- [ ] أي إحالة داخلية (§1/§4/§16) هدفها موجود فعلاً في الماستر نفسه.
- [ ] أي إحالة لماستر آخر (إن وُجدت) نثراً باسم الملف مع مساره، وبعد قرار شكل الماستر الموثق — لا رابط ويكي.

## د) الأرقام والمصادر

- [ ] **كل رقم له مصدر؟** كل نسبة % وكل مبلغ $ وكل عدد وكل مدة له مصدر (ملف + موضع) مسجَّل في ورقة العمل. رقم بلا مصدر لا يدخل الماستر.
- [ ] لا رقم محوَّل من مثال/قصة إلى قاعدة عامة (benchmark) بلا دليل مستقل — «قاعدة المثال» [REPORTED].
- [ ] أي رقم متعارض مع مصدر آخر مذكور الخلاف صراحةً (اعرض الطرفين — قاعدة معاذ) ولا يُحسم بصمت.
- [ ] التواريخ والأسماء (أشخاص/كتب/شركات) كما وردت في المادة الخام، بلا اختراع.
- [ ] لا اقتباس حرفي منسوب لمصدر لم يُقرأ فعلاً.
