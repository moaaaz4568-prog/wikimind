## 4. التوصية: أفضل طريقة عامة للمرحلة 3

### 4.1 المبدأ

**نظام عام صغير يعمل محلياً بأقل اعتماديات، والكلمات أولاً، والكثيف اختياري مقيس لاحقاً — لا خدمة سحابية مدفوعة ولا مفاتيح إطلاقاً.** [PROPOSED]

### 4.2 خط الأنابيب الموصى به

```
ملفات المستخدم (md/txt) — أي دومين، أي لغة
  │  ingest: جرد + manifest.jsonl (مسار، sha256، بايت، كلمات، persona)
  │         + dedupe بالمحتوى + تسجيل المستبعدين (مكرر/مؤشر/صغير)
  ▼
استخراج مصطلحات/مفاهيم: TF-IDF (يدوي/numpy) + YAKE (بلا موديل) أولاً
  │  — KeyBERT لاحقاً فقط إن وُجد موديل تضمين أصلاً (يعيد استخدام نفس الموديل)
  ▼
بناء ماسترز بسكيل make-master (ماستر واحد لكل دومين له مادة خام)
  │  — الماستر ملف عادي قابل للفهرسة والاستشهاد مثل أي مصدر
  ▼
تقطيع: عنوان/فقرة وحدةً، جدول/قائمة مقطع واحد، ونطاق محارف احتياطاً للنص بلا عناوين
  │  — كل مقطع: persona + raw_path + chunk_id + type + offset + sha
  ▼
فهرس BM25 أولاً (الأساس الوحيد في v0.1) — ثم اختيارياً: كثيف صغير + RRF
  ▼
واجهة سؤال (CLI أولاً): فلتر persona إجباري + استشهاد بالمقطع الخام
  + «لا أعرف» عند غياب الدليل + عرض الطرفين عند التناقض
  ▼
تقييم: 20 سؤالاً معروفاً من محتوى العيّنة الفعلي + Recall@k + فحص الاستشهاد
  — thresholds تبقى null حتى أول قياسين
```
